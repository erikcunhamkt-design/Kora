# src/pages — Telas (rotas)

Componentes de página que o React Router mapeia para cada rota da aplicação
(ex.: `Financeiro`, `CRM`, `WhatsApp`, `Configuracoes`). São o ponto de entrada
visual de cada área. A UI reutilizável fica em [`../components`](../components),
o estado/lógica em [`../hooks`](../hooks) e o acesso a dados em
[`../repositories`](../repositories).
