# src/components/ui — Design System

Primitivos de interface (shadcn/ui sobre Radix + Tailwind): `Button`, `Dialog`,
`Input`, `Select`, `Toast`, etc. É a base visual compartilhada por toda a
aplicação. Mantenha estes componentes genéricos e acessíveis — sem lógica de
negócio (essa mora nos módulos de `../` e nos hooks).
