# src/components — Componentes de UI (frontend)

Componentes React reutilizáveis, organizados por módulo (`dashboard/`, `crm/`,
`vendas/`, `whatsapp/`, `clientes/`, etc.). O design system base fica em
[`ui/`](ui). Aqui é **frontend**: apresentação e interação — sem acesso direto a
dados, que fica em [`../hooks`](../hooks) e [`../repositories`](../repositories).
