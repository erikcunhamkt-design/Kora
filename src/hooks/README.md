# src/hooks — Hooks (estado e lógica)

Hooks React que encapsulam estado, efeitos e regras de uso da aplicação
(ex.: `useFinance`, `useClients`, `useCurrentWorkspace`, `useFormat`). Orquestram
os [`../repositories`](../repositories) para ler/gravar dados e expõem valores já
prontos para a UI em [`../pages`](../pages) e [`../components`](../components).
