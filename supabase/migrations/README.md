# supabase/migrations — Banco de dados (schema/RLS)

Migrações SQL versionadas do Postgres do Supabase: tabelas, índices, políticas de
RLS, funções e triggers. É o **banco de dados**. Aplicadas em ordem cronológica
pelo Supabase CLI (`supabase db push`). Nunca edite uma migração já aplicada —
crie uma nova migração para qualquer alteração.
